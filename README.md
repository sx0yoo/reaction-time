# reaction-time# 반응속도 실험 · Reaction Time Study

시각 자극(색깔), 언어 자극(글자), 청각 자극(소리)에 대한 반응속도를 비교하는 실험 사이트입니다.

총 27회 (3단계 × 9회) 시도를 진행하고, 결과를 Google 스프레드시트에 자동으로 기록합니다.

---

## 📋 실험 구성

| 단계 | 자극 | 시도 횟수 |
|---|---|---|
| 1. **색깔** | 화면 배경이 빨강/파랑/초록으로 변경 | 9회 (각 3회) |
| 2. **글자** | 검은색 글자로 "빨강"/"파랑"/"초록" 표시 | 9회 (각 3회) |
| 3. **소리** | TTS로 "빨강"/"파랑"/"초록" 음성 재생 | 9회 (각 3회) |

각 단계 내에서 색깔 순서는 무작위로 섞입니다.

---

## 🚀 설치 방법

### 1단계 — Google 스프레드시트 + Apps Script 설정

1. [Google Drive](https://drive.google.com) 에서 새 **Google 스프레드시트**를 만든다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭한다.
3. 기본 코드(`function myFunction() { ... }`)를 모두 지우고, **`apps-script.gs`** 파일의 내용 전체를 복사해서 붙여넣는다.
4. 디스크 아이콘으로 저장(Ctrl/Cmd + S).
5. 우측 상단 **배포 → 새 배포** 클릭.
6. 좌측 상단 ⚙️ 아이콘 → **웹 앱** 선택.
7. 다음과 같이 설정:
   - **설명**: 반응속도 실험
   - **다음 사용자 인증으로 실행**: 나
   - **액세스 권한이 있는 사용자**: **모든 사용자** ← 중요
8. **배포** 클릭 → Google 계정 권한 승인.
9. 표시된 **웹 앱 URL** 을 복사한다. (예: `https://script.google.com/macros/s/.../exec`)

> ⚠️ Apps Script 코드를 수정한 뒤에는 **반드시 "배포 관리"에서 새 버전으로 재배포**해야 변경사항이 반영됩니다.

### 2단계 — `index.html` 에 URL 붙여넣기

`index.html` 파일을 열고, 상단의 `CONFIG` 블록에서 다음 줄을 찾는다:

```javascript
GOOGLE_SCRIPT_URL: 'YOUR_GOOGLE_APPS_SCRIPT_URL_HERE',
```

작은따옴표 사이에 1단계에서 복사한 URL을 붙여넣는다:

```javascript
GOOGLE_SCRIPT_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
```

### 3단계 — GitHub Pages 배포

1. GitHub에서 **새 저장소(repository)** 를 만든다. (예: `reaction-time-experiment`)
2. `index.html` 파일을 저장소에 업로드한다. (드래그앤드롭 또는 git push)
3. 저장소의 **Settings → Pages** 로 이동.
4. **Source** 를 `Deploy from a branch` 로, **Branch** 를 `main` (또는 `master`) / `/(root)` 로 선택하고 저장.
5. 1~2분 후 `https://<사용자이름>.github.io/<저장소이름>/` 에서 사이트에 접속할 수 있다.

## 🧪 사용 방법

1. 사이트에 접속한다.
2. **학번**과 **이름**을 입력하고 "실험 시작"을 클릭한다.
3. 안내 화면에서 `Space` 를 눌러 진행한다.
4. 각 단계 시작 전 안내가 나오면 `Space` 로 시작한다.
5. **자극이 나타나면 즉시 `Space` 키**를 누른다.
6. 27회 시도가 모두 끝나면 결과 화면이 표시되고, 데이터가 스프레드시트로 자동 전송된다.

> 💡 **권장 브라우저**: 한국어 TTS 호환성을 위해 **Chrome** 또는 **Edge** 를 사용하세요. (Firefox/Safari는 한국어 음성이 없을 수 있습니다.)

## ⚙️ 설정 변경 (선택사항)

`index.html` 상단의 `CONFIG` 블록에서 다음 값들을 조정할 수 있습니다:

```javascript
const CONFIG = {
  GOOGLE_SCRIPT_URL: '...',
  WAIT_MIN: 1200,    // 자극 전 최소 대기시간 (ms)
  WAIT_MAX: 2800,    // 자극 전 최대 대기시간 (ms)
  FEEDBACK_MS: 1300, // 반응 후 RT 표시 시간 (ms)
  // ...
};
```

## 🛟 문제 해결

**Q. "Apps Script URL이 아직 설정되지 않았습니다" 라고 나옵니다.**
→ `index.html` 의 `CONFIG.GOOGLE_SCRIPT_URL` 에 본인의 웹 앱 URL을 붙여넣었는지 확인하세요.

**Q. 스프레드시트에 데이터가 안 들어와요.**
→ Apps Script 배포 시 "액세스 권한이 있는 사용자"를 **모든 사용자** 로 설정했는지 확인하세요.  
→ Apps Script를 수정한 뒤에는 반드시 "배포 관리"에서 **새 버전**으로 재배포해야 합니다.

**Q. 소리가 안 나옵니다.**
→ Chrome 또는 Edge에서 실행하세요. 또한 페이지 로드 후 한 번이라도 키보드/마우스 상호작용이 있어야 음성 재생이 허용됩니다 (브라우저 정책).

**Q. 전송이 실패했어요.**
→ 결과 화면의 **"CSV 백업 다운로드"** 버튼으로 데이터를 직접 받을 수 있습니다.
